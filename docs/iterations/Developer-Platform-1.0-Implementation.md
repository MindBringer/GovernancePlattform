# Arbeitspaket: Developer Platform 1.0

## Umfang
Zentrale Konfiguration, gemeinsame PowerShell-Funktionen, Export/Unpack/Validate/Build/Import/Publish/Release, CI-Syntaxprüfung und verbindlicher ALM-Leitfaden.

## Abnahme
- Konfiguration an Repository angepasst.
- `Validate.ps1` erfolgreich.
- `Build.ps1` erzeugt eine unmanaged ZIP.
- Import mit `-WhatIf` geprüft und anschließend in DEV erfolgreich.
- Feature-Branch gepusht und Pull Request erstellt.
- Bestehende App-Funktionalität im Smoke-Test bestätigt.
