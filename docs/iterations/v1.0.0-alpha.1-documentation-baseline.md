# Iteration v1.0.0-alpha.1 – Entwicklungsprozess und Dokumentationsbasis

**Status:** Bereit zur Prüfung  
**Iterationstyp:** Dokumentation / ALM-Grundlage  
**Branch:** `feature/canvas-v1-foundation`  
**Ziel-Commit:** `docs(dev): add iteration workflow and roadmap`

## Ziel

Die erste Iteration etabliert einen verbindlichen, reproduzierbaren Entwicklungsablauf für das Governance Portal. Sie schafft noch keine neue Canvas-Funktion, sondern definiert den Prozess, nach dem alle folgenden Funktionsiterationen umgesetzt, gebaut, getestet und in Git übernommen werden.

## Umfang

Enthalten:

- `docs/Development-Iteration.md` als ausführliche Arbeitsanweisung und Cheat-Sheet
- `docs/Roadmap.md` als versionierte Entwicklungsplanung
- dieses Iterationsprotokoll mit Ziel, Abnahmekriterien und Prüfschritten
- Festlegung von Commit-Konventionen, Definition of Done und Abbruchkriterien
- Einordnung des PAC-basierten Canvas-Pack/Unpack-Prozesses

Nicht enthalten:

- Änderungen an Canvas-Screens oder Power-Fx-Formeln
- Änderungen an SharePoint-Listen oder Provisioning
- Solution-Build oder Import
- produktive Bereitstellung

## Akzeptanzkriterien

- [ ] Dateien liegen unter `docs/` in der vorgesehenen Repository-Struktur.
- [ ] Der Ablauf deckt Branching, Entwicklung, Tests, Pack, Import, Smoke-Test, Commit, Pull Request und Tagging ab.
- [ ] Befehle sind für macOS mit PowerShell 7 formuliert.
- [ ] Die vorhandenen Repository-Pfade und Canvas-Dateinamen werden verwendet.
- [ ] Die Roadmap beginnt mit dieser Dokumentationsiteration.
- [ ] App Foundation ist als nächste Iteration `v1.0.0-alpha.2` eingeplant.
- [ ] Markdown-Dateien lassen sich ohne fehlerhafte Codeblöcke darstellen.
- [ ] Der Commit enthält keine lokalen Artefakte oder Zugangsdaten.

## Prüfschritte

Nach dem Entpacken im Repository-Stamm:

```powershell
git status --short
Get-ChildItem "docs" -Recurse
Get-Content "docs/Development-Iteration.md" -TotalCount 30
Get-Content "docs/Roadmap.md" -TotalCount 30
git diff --check
```

Dateien übernehmen und committen:

```powershell
git add docs
git diff --cached --check
git diff --cached --stat
git commit -m "docs(dev): add iteration workflow and roadmap"
git push -u origin feature/canvas-v1-foundation
```
