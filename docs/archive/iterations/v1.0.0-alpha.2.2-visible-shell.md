# Iteration v1.0.0-alpha.2.2 – Sichtbare Shell und Navigation

## Ziel

Die technische Foundation wird zu einer sichtbaren, bedienbaren App-Shell erweitert. Die im Studio registrierten Control Templates `label` und `gallery` werden nun vollständig aus dem Experimental-Quellstand verwendet.

## Enthalten

- App-Version auf `1.0.0-alpha.2.2` angehoben.
- Sichtbarer Header mit App-Titel, Umgebung, Version und Benutzername.
- Responsive Navigation mit Lang- und Kurzbezeichnungen.
- Klickbare Gallery-Navigation über `gblCurrentPage`.
- Dynamischer Seitentitel und Modul-Platzhalter im Workspace.
- Footer mit Initialisierungsstatus.
- Busy-Overlay mit Statusmeldung.
- Aktiver Navigationseintrag wird über den stabilen Schlüssel hervorgehoben.
- Navigationstext wird vertikal mittig ausgerichtet.

## Smoke-Test

1. `pwsh ./powerplatform/scripts/Build.ps1` erfolgreich ausführen.
2. Unmanaged Solution in DEV importieren.
3. App öffnen und `App.OnStart` ausführen.
4. Prüfen, dass Header, Navigation, Workspace und Footer sichtbar sind.
5. Mehrere Navigationseinträge auswählen; Seitentitel und Hervorhebung müssen wechseln.
6. Browserbreite unter 900 Pixel reduzieren; Navigation muss auf ShortLabels wechseln und der Benutzername ausgeblendet werden.
7. `Set(gblBusy; true);; Set(gblBusyMessage; "Test")` ausführen; Overlay muss sichtbar sein.
8. Danach `Set(gblBusy; false)` ausführen.
9. App Checker prüfen und verbleibende Warnungen dokumentieren.

## Definition of Done

- Build erfolgreich.
- Import erfolgreich.
- App startet ohne Formelfehler.
- Navigation ist klickbar und responsive.
- Sichtbare Shell entspricht dem beschriebenen Layout.
- App Checker enthält keine blockierenden Fehler.
- Aktualisierter Experimental-Quellstand ist committed und gepusht.
