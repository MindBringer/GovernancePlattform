# Iteration v1.0.0-alpha.2.1 – UI-Control-Bootstrap

## Ziel

Diese Korrekturiteration behebt die Collection-Initialisierung und bootstrapped einmalig die klassischen sichtbaren Controls im Power Apps Studio.

Der vorhandene PAC-Experimental-Quellstand enthält aktuell nur die Control Templates `appinfo`, `screen`, `Host` und `groupContainer`. Label, Button und Gallery können deshalb nicht zuverlässig ausschließlich durch das Hinzufügen von YAML erzeugt werden: Neben der Screen-YAML müssten auch die passenden Control-Template- und Paketdefinitionen erzeugt werden. Diese Dateien werden einmalig durch Power Apps Studio angelegt.

Nach dem anschließenden Export und `pac canvas unpack` sind die Control-Typen Bestandteil des Repository-Quellstands und können in Folgeiterationen kontrolliert verändert und wiederverwendet werden.

## Enthaltene Korrekturen

- `colNotifications`, `colRecent` und `colFavorites` werden mit einem definierten Schema angelegt und anschließend geleert.
- App-Version wird auf `1.0.0-alpha.2.1` gesetzt.
- Theme wird um `ColorTextMuted`, `ColorSelected` und `ColorSuccess` erweitert.
- Navigation enthält zusätzlich `ShortLabel` für eine spätere kompakte Darstellung.
- `Pack-Canvas.ps1` verwendet `--layout Experimental --overwrite`.

## Einmaliger Studio-Bootstrap

## Speichern und zurück in Git überführen

Nach dem Anlegen der Controls:

1. App speichern und veröffentlichen.
2. Solution erneut unmanaged exportieren.
3. Exportierte Solution nach `artifacts/inbound` legen.
4. Solution erneut entpacken.
5. Canvas erneut im Experimental-Layout entpacken.
6. Prüfen, dass `ControlTemplates.json` mindestens `label` und `gallery` enthält.
7. Den aktualisierten Quellstand committen.

## Smoke-Test

- App startet ohne Formelfehler.
- Header zeigt App-Name, DEV und Version.
- Navigation ist sichtbar.
- Auswahl eines Navigationseintrags ändert `gblCurrentPage`.
- Seitentitel folgt der Navigation.
- Footer zeigt `Bereit`.
- Bei `Set(gblBusy; true)` ist das Busy-Overlay mit Text sichtbar.
- Schmale Browserbreite zeigt die ShortLabels.

## Definition of Done

- Collection-Fehler beseitigt.
- Sichtbare Controls im Studio einmalig erzeugt.
- Erneuter Export und Unpack erfolgreich.
- `label` und `gallery` sind im Control-Template-Bestand enthalten.
- Smoke-Test bestanden.
